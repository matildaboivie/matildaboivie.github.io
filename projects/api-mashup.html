A movie-to-book recommendation experience built by combining data from TMDB and Open Library.

Try the project →

THE IDEA

What should I read next?

The idea was to connect two types of entertainment: movies and books. The user enters a movie they like and receives a book recommendation based on the movie's genre.

HOW IT WORKS

Two APIs, one recommendation

The user's movie search is sent to the TMDB API, which returns information about the movie and its genre.

That genre is then used in a second request to the Open Library API to find a matching book.

THE PROCESS

From input to recommendation

Movie search → TMDB → genre → Open Library → book recommendation.

The project gave me hands-on experience with asynchronous JavaScript, fetch requests, API responses and combining information from multiple data sources into one user experience.

TOOLS

HTML · CSS · JavaScript · Fetch · TMDB API · Open Library API
