DATA COLLECTION / NODE.JS

A web scraping project built with Node.js to collect company information from multiple web pages and transform it into a structured dataset.

THE PROJECT

From website to dataset

The goal of the project was to collect company information automatically instead of gathering the data manually. The script visits multiple pages, extracts relevant information and saves the results in a structured CSV file.

THE PROCESS

How it works

The scraper was built using Node.js. Fetch is used to request the web pages and Cheerio is used to parse the HTML and locate the information needed. The script extracts company name, registration number, phone number and address before exporting the collected information into a CSV file.

TOOLS

Node.js · Cheerio · Fetch · CSV · HTML

This project introduced me to automated data collection and how unstructured information on a website can be transformed into structured data that can be analyzed or used in other projects.
